# PT-Scoutdigo-V1.2
Instructions to play Scoutdigo V1.2 Web Port!

VERY VERY FIRST STEP: Make a new code space

*Step 1:* Do this command: sudo apt-get update && sudo apt-get install -y p7zip-full && gh release download r1 -R burnedpopcorn/PT-Scoutdigo-Web-Port -p indigomod_WebBuild_r1.7z && 7z x indigomod_WebBuild_r1.7z && rm indigomod_WebBuild_r1.7z

*Step 2:* Do this command: python3 -m http.server 8080

*Step 3* Just click "betterrunner.html" when you open your port.


It should Work!!
# *If you have an existing code space that already downloaded the files:*

Step 1: This command; python3 -m http.server 8080

Step 2: Open your port

Step 3: Click "betterrunner.html"

That's it!
